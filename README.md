# LLaMA-4 Maverick Data Analyst

A Streamlit app that lets you upload a document, spreadsheet or image and ask questions about it, answered by Llama 4 Maverick through the Together AI API, with any generated Python/matplotlib code run and its chart shown in the app.

## Features

- Upload CSV, Excel (`.xlsx`), PDF, plain text (`.txt`) and image (`.png`, `.jpg`, `.jpeg`) files.
- Preview of the extracted file content (or the image) before asking a question.
- Natural-language questions about the uploaded file, answered by `meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8`.
- Images are sent to the model as multimodal input.
- Python code in the model's answer is shown, executed, and any matplotlib figure is rendered in the app.
- Questions and answers from the current session are listed in a chat history.

## How it works

1. The uploaded file is converted to content the model can read:
   - CSV / Excel: loaded with pandas; the first 100 rows are converted to text.
   - PDF: text extracted with PyMuPDF, truncated to the first 5,000 characters.
   - TXT: the first 1,250 characters.
   - Images: re-encoded as PNG and sent base64-encoded.
2. Your question and the file content are combined with a data-analyst prompt that asks the model for a short explanation followed by Python code in a Markdown code block.
3. The request is sent to the Together AI chat completions endpoint (`temperature` 0.3, `max_tokens` 2000).
4. The response is split into the explanation and the Python code blocks.
5. Each code block is displayed and run with `exec()`; the resulting matplotlib figure is shown with `st.pyplot`. If there is no code, the plain response is shown.
6. The question and response are added to the chat history in Streamlit session state.

## Tech stack

- Python
- Streamlit
- Together AI API (via `requests`)
- Llama 4 Maverick (`meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8`)
- pandas and openpyxl
- PyMuPDF
- Pillow

## Setup and run

1. Clone the repository:

   ```bash
   git clone https://github.com/AgrawalShiven/llama4-data-analyst.git
   cd llama4-data-analyst
   ```

2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Provide your Together AI API key, either in a `.env` file in the project directory:

   ```
   TOGETHER_API_KEY=your-api-key
   ```

   or as an environment variable:

   ```bash
   export TOGETHER_API_KEY="your-api-key"
   ```

   `main.py` loads `.env` with `python-dotenv`, reads the key with `os.getenv`, and stops with an error if it is missing.

4. Start the app:

   ```bash
   streamlit run main.py
   ```

## Limitations and notes

- Code generated by the model is executed with `exec()` in the app's own process, without any sandboxing. Treat this as a prototype for trusted, local use only.
- Inputs are truncated before being sent to the model: the first 100 rows for CSV/Excel, the first 5,000 characters for PDFs and the first 1,250 characters for text files. Answers about content beyond these limits will not reflect it.
- Each question is sent to the model on its own; earlier questions in the chat history are displayed but not passed back to the model as context.
